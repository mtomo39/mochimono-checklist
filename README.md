# 持ち物チェックリスト

階層構造で管理できる、シンプルな持ち物チェックリストアプリです。
サーバー不要・完全無料で、GitHub Pages + PWA(ホーム画面に追加)で動作します。

## 特徴

- 📋 複数のチェックリストを保持できる
- 🌳 項目を階層構造(親子関係)で管理できる
- ✅ 親項目のチェックは子・孫階層まで自動で連動する
- 🔢 各階層ごとに「チェック済み数 / 全体数」を表示
- 👁 「すべて表示 / 未チェックのみ表示」の切り替え
- ✏️ リスト名・項目名はタップしてその場で編集
- ↕️ 項目の並び替え・階層の変更(上へ/下へ/親階層へ/子階層へ)をボタンで操作
- 💾 データはブラウザ内(localStorage)に自動保存
- 📤 JSON形式で書き出し・読み込み(バックアップ・引き継ぎ用)
- 📱 iPhoneのホーム画面に追加してアプリのように使える(PWA)

## 使い方

1. このリポジトリの中身をGitHub Pagesで公開する
2. iPhoneのSafariで公開したURLを開く
3. 共有ボタン →「ホーム画面に追加」

## 技術構成

- HTML / CSS / JavaScript のみ(フレームワーク・ビルド不要)
- データ保存は `localStorage`(サーバー・データベース不要)
- オフライン対応のため Service Worker(`sw.js`)でキャッシュ

## 注意事項

データは端末のブラウザ内にのみ保存されます。Safariの「履歴とWebサイトデータを消去」などを行うとデータが失われるため、
定期的に「書き出し(JSON)」機能でバックアップを取ることをおすすめします。

## ファイル構成

| ファイル | 役割 |
|---|---|
| `index.html` | 画面構造 |
| `style.css` | 見た目(iOS リマインダー風デザイン) |
| `app.js` | アプリのロジック |
| `manifest.json` | PWA設定 |
| `sw.js` | オフラインキャッシュ用 Service Worker |
| `icon-192.png` / `icon-512.png` | アプリアイコン |
